# Portfolio

**Live:** [portfolio-seven-dusky-78.vercel.app](https://portfolio-seven-dusky-78.vercel.app)

Personal portfolio site — hero, about, experience, education, skills, and project
sections for AI Transformation & Analytics consulting work.

## Stack

React + TypeScript, Vite, Gemini API (server-side) for dynamic content generation.

## Running locally

```bash
npm install
cp .env.example .env.local   # set GEMINI_API_KEY
npm run dev
```
